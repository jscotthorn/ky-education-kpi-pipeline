# What KDE changed, and how the pipeline handled it

Each row is a change evidenced in this repo, a pull request, an issue, or a KDE page cited in [kde-guidance-sources.md](kde-guidance-sources.md). KDE quotations from CHG-2022 and the 15 October 2026 release bulletin were re-fetched. Other KDE quotations are from the 25 October 2026 research attachment and were not fetched again. Pipeline handling is from this branch.

A KDE guidance flag on a row is not a change to a decision. Records are in [README.md](README.md).
